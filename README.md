# MonoGameLibrary

Created by following the tutorial here: https://docs.monogame.net/articles/tutorials/building_2d_games/index.html

Separated out for re-useability and expanding upon

## Project Structure

| Folder | Purpose |
|--------|---------|
| Audio/ | Sound effect and music playback |
| Graphics/ | Sprites, texture atlases, animation, and tilemap rendering |
| Input/ | Keyboard, mouse, and gamepad state tracking |
| Math/ | Geometric primitives and collision math helpers |
| Physics/ | Colliders, physics bodies, and force application |
| Scenes/ | Scene lifecycle and scoped content management |
| Utilities/ | Diagnostic logging |
